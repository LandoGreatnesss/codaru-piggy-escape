Piggy Escape Game (Codaru Challenge 1)

Description

This is a text-based escape room game inspired by the Roblox game "Piggy." In this game, players navigate through a series of choices, trying to escape the house while avoiding the Piggy character.

This project is designed for Codaru's challenge of creating a mini-program with less than 1,000 characters of code. The game has two versions:

Clean Version: Contains comments for readability.
Minified Version: Contains the same logic as the clean version but with all unnecessary spaces and line breaks removed to meet the 1,000-character limit.
How to Play

Enter your username when prompted.
Follow the storyline and make choices to escape the house.
Choose wisely! Piggy is lurking around, and your choices will determine your fate.
Play through the game by answering the prompts!
How to Run the Code

Clone the repository to your local machine:
git clone https://github.com/landogreatnesss/codaru-piggy-escape
Navigate to the project folder in your terminal or command prompt.
Run the game with Python:
python3 codaru-piggy-escape.py
Enjoy!
